# Digital Log Books

e-Logbook for MBBS CBME (NMC competency-based curriculum): replaces paper departmental logbooks with institutional-email logins, digital competency entries and faculty e-signatures.

- `prototype/index.html` — clickable UI prototype (student entry, faculty e-sign queue, HOD dashboard, MEU competency master, signed PDF export). Sample data only.
- Proposal and requirements: maintained as a shared document for MEU, IEDC and administration review.
